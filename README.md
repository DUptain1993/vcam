# 虚拟摄像头

一个基于 Xposed / LSPosed / LSPatch 的 Android 虚拟摄像头模块，可将应用获取到的真实摄像头画面替换为本地视频、图片或网络流，并提供基础的音频与播放控制。

## 主要功能

- 使用本地视频替换摄像头画面
- 支持 Camera1 / Camera2
- 支持图片替换拍照结果
- 支持麦克风静音、音频替换和视频原声
- 支持随机播放、通知栏切换和网络流
- 支持 LSPosed、LSPatch、EdXposed 与传统 Xposed

## 基本使用

安装并启用模块后，为目标应用配置作用域。首次进入目标应用相机界面时，根据提示准备对应分辨率的视频，并将其命名为 `virtual.mp4`。

常用路径：

```
/内部存储/DCIM/Camera1/virtual.mp4
```

如果目标应用无法访问公共存储，可使用其私有目录：

```
/内部存储/Android/data/[应用包名]/files/Camera1/virtual.mp4
```

重新打开目标应用后，摄像头画面即可被替换。

## 说明

部分应用或系统相机可能因实现方式不同而无法正常 Hook；出现黑屏、花屏或方向异常时，优先检查视频分辨率、编码格式与文件路径。

项目仅供学习、研究与合法用途使用，请遵守当地法律法规。
